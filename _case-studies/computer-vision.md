## Problema

Los problemas de clasificación y detección visual requieren pipelines reproducibles que integren preprocesamiento de imágenes, entrenamiento de modelos y presentación de resultados. Los notebooks aislados no permiten comunicar los resultados de forma accesible a stakeholders no técnicos.

## Arquitectura

Implementé un pipeline de Computer Vision con dos componentes:

**Pipeline de análisis**: Notebooks Jupyter con preprocesamiento de imágenes, entrenamiento y evaluación de modelos de visión por computador. Experimentación documentada paso a paso.

**Interfaz de visualización**: Componente HTML para presentación interactiva de resultados, permitiendo explorar las predicciones del modelo de forma visual.

```
Imágenes → Preprocesamiento → Modelo CV → Evaluación → Visualización HTML
```

## Resultado

- **Pipeline reproducible** de entrenamiento y evaluación
- **Visualización web** de resultados del modelo
- **Código documentado** en notebooks paso a paso

## Impacto

- Demostración de capacidades en visión por computador
- Pipeline reutilizable para nuevos datasets de imágenes
- Presentación accesible de resultados técnicos mediante interfaz web
